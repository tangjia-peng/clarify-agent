# 评估资料与结果看板

本目录提供20题评估集、指标说明、跑题结果汇总报告、Excel成绩单和自动录入脚本。

## 查看结果

打开 [攻略Agent评估成绩单.xlsx](攻略Agent评估成绩单.xlsx)：

- `A-B对比`：三模式汇总结果。
- `成绩单`：逐题、逐模式评分。
- `瞎编核查`、`硬信息核查`、`白问核查`：依据、判定及人工复核字段。
- `瞎编核查B2`、`硬信息核查B2`：B2独立核查。
- `填写说明`：填写规则。

上传版本保留现有数据、474个公式、样式与布局，不做重算或清空。它是当前保存的结果快照；报告所引用的历史成绩单口径与日期在报告中另行标注。

## 重跑与录入

配置主模型、向量接口、裁判及模拟用户后，从项目根目录执行：

```powershell
python command.py eval --skip-record
uv run --cache-dir .uv-cache --with openpyxl python result/自动录入.py
```

第一步跑题与模型裁判会调用接口；第二步只读取本地裁判输出并更新Excel，不调用模型。录入脚本按自身目录定位成绩单，无需另设绝对路径。

工作簿已经有结果，重新录入会更新相应题目；未重跑题目的历史结果会保留。开始新批次前请另存工作簿，并关闭正在占用该文件的Excel/WPS窗口。复核仍需核对逐项语义判定与证据。

完整对话、messages快照和裁判原文保留在运行者本地，不随公开仓库发布，可通过评测脚本生成。
