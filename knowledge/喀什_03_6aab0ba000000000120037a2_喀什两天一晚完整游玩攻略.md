Day1️⃣｜南疆烟火·牛羊大巴扎 + 喀什古城东区
上午：喀什牛羊大巴扎（原生态必体验）仅每周四、周日开市
南疆最原生态活畜集市，看牧民袖筒议价、成群牛羊，感受最地道的西域市井烟火，建议中午11–14点前往，氛围最热闹。
下午—晚上：喀什古城东区
✅10:30 古城东门开城仪式（周一休演，建议提前15分钟占位）
✅东区完整不走回头路打卡路线：
花盆巴扎 → 古丽的家 → 空中花园 → 铁业公社 → 老城角落咖啡馆 → 木器巴扎 → 花帽巴扎 → 汗巴扎夜市 → 昆仑塔古城全景机位 → 耿恭祠
东区主打市井热闹、网红机位、南疆美食，傍晚逛汗巴扎夜市，灯火烟火氛围感拉满。
Day2️⃣｜千年人文·喀什古城西区 + 喀什博物馆
上午:喀什博物馆
读懂喀什最好的方式：先看千年历史，再逛人间古城
⚠️重要须知：
周一闭馆，必须提前在官方微信公众号实名预约，携带身份证原件入馆，免费参观，建议游玩2小时
下午：喀什古城西区（文艺安静、氛围感拉满）
✅官方演出：19:00 西域公主选郎、驼队巡游（周一休演，百年老茶馆二楼露台最佳观赏位）
✅西门进入·西区完整打卡路线（全程顺向不绕路）：
布袋巷 → 彩虹巷 → 爷爷的爷爷的爸爸的馕 → 百年老茶馆 → 油画一条街 → 古董街 → 艾提尕尔清真寺
西区主打原住民生活、沉浸式感受老城底蕴。
